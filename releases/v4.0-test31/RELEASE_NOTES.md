# 医键住院管理 4.0-test31

## 本版重点

- 主界面改为窄状态栏 + 全幅患者列表，移除旧底部导航。
- 连接状态灯统一展示手机蓝牙 HID 与开发板连接状态，长按进入连接配置。
- 设置图标改为平顶正六边形与中心圆圈。
- 新增设置主菜单：连接配置、大模型配置、技能配置、关于。
- 连接配置采用电脑与开发板统一扫描、配对和主动连接流程。
- 大模型配置支持 DeepSeek、小米 MIMO、手动获取模型列表、模型选择和 API Key。
- 新建与编辑患者简化为姓名、性别、年龄三项必填资料。
- 点击患者直接进入病历工作台，长按可编辑资料或彻底删除患者。
- 删除患者时同步清除加密病例记录与 WebView 本机草稿。
- 病历工作台输入资料加号移至右侧，病例输出标题栏加入终端状态和“输出到终端”。
- 终端状态与输出按钮支持长按进入连接配置，原有输出、暂停与停止逻辑保留。
