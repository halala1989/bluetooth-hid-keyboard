# 医键住院管理 v4.0-test18

- applicationId：`com.hidble.carekeyboard`
- versionCode：`40017`
- 版本名称：`4.0-test18`
- APK：`医键住院管理-v4.0-test18.apk`

## 主要功能

- 住院患者列表与基本信息管理，基本信息仅保留姓名、性别、年龄。
- 生成文书同步到患者详情页病例文书列表。
- 纵屏病历工作台：自然语言时间线、补充自然语言资料、全部病历文书类型。
- 入院记录、首次病程、手术同意书、术前小结、术前讨论、手术记录、出院小结等模型生成流程。
- Markdown 全局书写规范、DeepSeek/MiMo 模型连接测试。
- 手机蓝牙 HID、Pico W、ESP32-S3、YD-ESP32-S3 和旧 ESP32 BLE HID 终端选择。
- 真实输出桥接及暂停、继续、完全停止控制。
- v4.0-test18 输出速度为旧版约两倍，第 8 档保留稳定上限，第 9、10 档突破保护。

## 已知边界

- 这是本地测试版，不是经过医疗器械注册或临床验证的生产系统。
- 真实模型输出依赖用户配置的 API Token。
- 外接板需要烧录对应版本固件；现有旧固件不会自动获得新版速度曲线。
- 正式使用前必须由医师核对所有病历内容并完成机构隐私、安全和合规审批。
