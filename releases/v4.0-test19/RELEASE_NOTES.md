## 本次更新

- 在“今日病区概览 → 书写规范”页面增加 AI 修改 Skill 区域。
- 用户可用自然语言说明要增加、删除或调整的书写规则。
- 点击“调用 AI 修改并保存”后，使用当前设置中的 DeepSeek 或 MiMo 返回完整 Markdown Skill。
- AI 修改成功后自动覆盖当前 Skill、刷新预览并全局应用。
- 调用中显示进度，失败时保留原 Skill，不写入不完整结果。
- 修改提示要求保留必要医疗文书栏目、患者隐私保护和医生审核要求，不将中医辨证改写成西医描述。

## 已知边界

- 使用前必须先在“设置 → 模型”配置并测试 DeepSeek 或 MiMo 的 API Token。
- AI 修改属于规则文本编辑，生成后的 Skill 仍应由医生审核，不能替代医院正式制度。
- 当前是本地测试版，不是经过医疗器械注册或临床验证的生产系统。
