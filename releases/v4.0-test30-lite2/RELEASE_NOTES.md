## 本次更新

- “选择终端并连接”现在进入专用二级页面。
- 页面分为上下两个区域。
- 上方区域专门处理手机蓝牙 HID：启动键盘、让电脑发现手机、选择已配对电脑和主动连接。
- 下方区域选择开发板：Pico W、ESP32-S3 Super Mini、YD-ESP32-S3 N16R8 和旧 ESP32 BLE HID。
- 选择开发板后会弹出“是否扫描附近蓝牙设备”。
- 扫描不再按旧名称或 Bridge 后缀过滤，会显示附近全部 BLE 设备。
- 每个扫描结果直接显示实际广播名称、MAC 地址和信号强度。
- 已配对设备合并进同一个列表，不再单独列在下方。
- 增加 Android 12 及以上所需的蓝牙广播权限。

## 已知边界

- 开发板扫描使用 BLE；仅支持经典蓝牙且不广播 BLE 的设备不会出现在列表中。
- 扫描列表会显示全部 BLE 设备，连接非键盘开发板不会成功。
- 当前完成构建，仍需在真实手机和开发板上验证扫描与连接。
