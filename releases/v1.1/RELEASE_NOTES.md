## 相比 v1.0 的变化

1. **一键开关**：进入 App 后，底部是「模拟蓝牙键盘」开关。打开开关：
   - 自动请求开启蓝牙（弹出系统授权）；
   - 自动把本机注册成蓝牙键盘（电脑端显示“手机蓝牙键盘”）。
2. **电脑端搜索**：开关打开后，到电脑 设置 → 蓝牙 → 添加设备，即可搜索到“手机蓝牙键盘”并配对。
3. 关闭开关 = 停止模拟键盘并断开连接。
4. 已配对设备列表保留在开关下方，首次配对后若电脑未自动连接，可点选电脑手动连接。

## 使用方法

1. 打开 App，点底部开关。
2. 系统弹出“开启蓝牙”，点允许。
3. 电脑：设置 → 蓝牙 → 添加设备 → 搜索“手机蓝牙键盘”并配对。
4. 顶部输入文字点发送；速度/常用语/中文模式用法不变。
