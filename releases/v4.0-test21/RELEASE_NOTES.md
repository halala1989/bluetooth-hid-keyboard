## 本次更新

- 入院记录、首次病程记录、普通病程记录、手术同意书等文书可以重复生成多份。
- 每份生成结果使用独立文书标签，不再覆盖同类型的上一份文书。
- 未保存文书持续保留在病例输出区，关闭并重新进入工作台后仍可继续查看和输出。
- 删除顶部的“保存草稿”按钮，把“保存到患者详情”移动到病例输出区底部。
- 只有点击底部保存按钮后，当前文书才会出现在患者详情页的病例文书列表。
- 长按病例输出区顶部标签会弹出确认框；删除未保存文书只影响工作台，删除已保存文书会同时移除患者详情中的对应记录。
- 患者详情可以同时保存并打开同一文书的多个不同版本。

## 已知边界

- 生成文书仍然必须配置 DeepSeek 或 MiMo API Token。
- 保存后的完整文书使用本地加密存储，不提供云端同步。
- 当前是本地测试版，不是经过医疗器械注册或临床验证的生产系统。
