## 相比 v11 的变化

1. **移除 Pico W**：删除 BLE 扫描/固件通信，改为 `BluetoothHidDevice`（Android 9+ 系统 API）把手机注册成标准蓝牙键盘。
2. **连接方式**：点“启动键盘”→ 手机以“手机蓝牙键盘”身份出现在电脑蓝牙设备中 → 电脑端配对 → 点已配对设备连接（多数电脑配对后自动连接）。
3. **中文输入 1:1 移植**：Alt+X / 十六进制 / 十进制 / GBK 四种模式和 SPEED 调速逻辑原样移植到手机端（TypingEngine），体验与 v11 一致。
4. **界面**：其余完全参照 v11——输入置顶（含速度、常用语），扫描/断开/发现设备移到最底部（改为“启动键盘/断开/已配对设备”）。
5. 版本号：versionCode 12 / versionName "12.0"；最低系统 Android 9（API 28）。

## 使用方法

1. 手机安装 APK，打开并开启手机蓝牙。
2. 点底部“启动键盘”，状态变为“键盘已启动”。
3. 电脑：设置 → 蓝牙 → 添加设备，选择“手机蓝牙键盘”并配对（手机上确认配对码）。
4. 回到 App，点底部“已配对设备”里的电脑连接（或等它自动连接）。
5. 顶部输入文本点发送；速度/常用语/中文输入模式用法与 v11 完全相同。

## 已知限制

- 需要 Android 9+ 且手机支持蓝牙键盘（HID Device）功能（大多数手机支持）。
- 部分手机 ROM 可能限制 HID Device 服务，需在系统蓝牙设置中确认。
- 中文输入仍然依赖电脑端 Windows 的 Alt 码输入（与 v11 相同，目标机无需装软件）。
