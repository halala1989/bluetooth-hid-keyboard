# 版本发布约定（phone-keyboard 产品线）

本分支（`phone-keyboard`）是独立的“手机蓝牙键盘”产品，版本号从 **1.0** 开始递增
（v1.0 → v1.1 → v1.2 → v1.3 → v1.4 → …）。Pico W 旧产品线在 `master` 分支（v10/v11…），两者互不影响。

## 规则（每次发布新版本时遵守）

1. **版本号递增**：当前最新号 +0.1。今天最新是 `v1.4`，下次就是 `v1.5`。
2. **产物归档**：把当次构建的 APK 复制到 `releases/vNN/` 下，命名带版本号：
   - `releases/vNN/PhoneBluetoothKeyboard-vNN.apk`
3. **发布说明**：每个版本目录写 `RELEASE_NOTES.md`，记录日期、功能变化、产物 SHA256、回滚方法。
4. **代码打 tag**：发布完成后打同名 git tag：`git tag v1.0`（每次递增）。
5. **更新 LATEST 指针**：`releases/LATEST` 文件内容改为最新版本号（如 `v1.0`）。
6. **最新副本**：仓库根目录 `PhoneBluetoothKeyboard-debug.apk` 始终是“最新版”。

> 应用标识：包名 `com.hidble.phonekeyboard`、应用名“手机蓝牙键盘”，与旧版 `com.hidble.keyboard` 互不覆盖，可同时安装。

## 回滚方法

- **代码回滚**（本产品线内）：`git checkout v1.0`
- **切回旧产品线**：`git checkout master`（Pico W 方案 v10/v11）
- **只回滚产物**：直接用 `releases/vNN/` 里的 APK 安装。
