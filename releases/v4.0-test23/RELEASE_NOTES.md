## 本次更新

- 修复手术同意书内容顺序异常。
- 手术同意书始终按“疾病介绍 → 方案一 → 方案二 → 方案三 → 后续方案 → 手术相关风险”显示和输出。
- 方案使用中文或阿拉伯数字编号时均会按编号排序。
- 相同编号的重复方案会自动去重，避免方案三在疾病介绍后和底部重复出现。
- 手机 HID 键盘全部 1–10 档速度较上一版再提高约 10%。
- 第 10 档最低按键延迟从 5ms 调整为 3ms，以进一步提高极限速度。
- 高速档位仍可能因电脑、蓝牙链路或目标应用处理速度出现丢字，可在输出弹窗或设置页手动降低档位。

## 已知边界

- 速度提升主要作用于手机蓝牙 HID 手机端控速；外接板实际速度仍受其固件版本影响。
- 当前没有连接真实电脑进行极限速度丢字率测试。
- 当前是本地测试版，不是经过医疗器械注册或临床验证的生产系统。
