## 修复内容

- **问题**：打开开关后电脑完全搜不到手机（很多安卓机在注册成 HID 键盘后会关闭蓝牙“可见性”）。
- **修复**：注册成蓝牙键盘成功后，App 自动弹出系统「对附近设备可见」授权（默认 5 分钟）；点“允许”后，
  电脑 设置 → 蓝牙 → 添加设备 就能搜到“手机蓝牙键盘”并配对。
- 若误点了不允许或超时：在系统蓝牙设置里开启“对附近设备可见”，或把开关关掉再打开重新触发。

## 使用方法

1. 打开 App，点底部开关。
2. 蓝牙授权点“允许”，随后出现“对附近设备可见”也点“允许”。
3. 电脑：设置 → 蓝牙 → 添加设备 → 搜索“手机蓝牙键盘”并配对。
4. 顶部输入文字点发送。
