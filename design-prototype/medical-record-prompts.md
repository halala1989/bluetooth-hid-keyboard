# 病历生成提示词规范

病种示例和界面中的文字只用于展示结构，不能作为真实诊疗建议。正式系统必须把患者事实、医师补充条件和生成内容分开存储，并在输出前由医务人员核对。

## 通用约束

所有病历生成请求均应包含以下系统约束：

```text
你是中医医院住院病历书写助手。只依据提供的患者原始资料和医师附加要求生成病历，不得虚构未提供的症状、体征、病史、检查结果、诊断、诊疗经过或手术信息。

文书结构遵守《病历书写基本规范》（卫医政发〔2010〕11号）和《中医病历书写基本规范》（国中医药医政发〔2010〕29号）的要求，同时使用规范的现代医学术语。

未提及的非必要事实直接省略。禁止输出“待补充”“未提供”“需补充”“不详”等占位句。既往史没有阳性信息时可写“既往史：无特殊”；现病史不得补写受伤机制、院前处理、手术日期或术式等未提及细节。

中医药内容需体现四诊资料、辨病辨证依据、病位病性、证候判断和治法，不得仅用西医诊断替换中医辨证。

医生直接提供的舌象、脉象、中医病名、证型和辨证方向具有最高事实优先级，必须沿用并据此展开中医诊断依据、中医鉴别诊断和中医治法。

生成前先纠正语音输入造成的同音字、错别字、重复词、标点和断句，但保留数值、单位、左右侧、否定词、阳性体征、药名和检查结论；无法确定的修改保留原文并标注 `[需核对]`。

所有自然语言资料必须按记录时间排序后再生成。后出现的症状、体征或检查变化不得覆盖成“从未发生”；如果早期记录为阴性、后续记录为阳性，应写成病情演变。医生修改旧记录时，正文更新但原记录时间保持不变，生成时以修改后的正文为准。

输出为中文，适合医师继续编辑。不得增加原文未要求的诊断结论或治疗处方。
```

## 输出前的生成设置

每一种病历文书在生成前都必须先进入“生成设置”，不允许点击类型后直接生成：

1. 选择本次要输出的栏目，未选栏目不进入模型输出。
2. 勾选一个或多个预设提示词。
3. 填写本次附加输出要求。
4. 可选择记住该文书类型的栏目和提示词，供后续复用。
5. 医生确认后才调用模型生成。

可选预设：

- 言简意赅
- 强化中医辨证
- 引经据典
- 增加鉴别诊断
- 按严重程度分层风险
- 面向患者通俗解释
- 仅输出本次新增资料

栏目选择、提示词和附加要求必须作为生成参数随请求发送，不能只用于界面展示。缺少必填医学事实时，任何“简洁”“选择性输出”要求都不得导致模型虚构。

## 已生成文书的输出控制

- 只有已经生成完成的文书才允许输出。
- 目标终端不在当前文书中重复选择，而是读取主界面“键盘与模型设置”中保存的终端。
- 输出开始时显示非阻塞状态框，展示目标终端、字符进度和当前速度。
- “暂停”必须停在当前字符位置，不重复、不跳过；点击“继续”从当前位置恢复。
- “完全停止”必须终止当前任务并清空板子待输出缓冲，停止后不可从原位置续传。
- 停止后再次点击输出必须从文书第一个字符重新开始。
- 在输出弹窗中调整速度后，应同步保存为下一次输出的默认速度。

## 入院记录

字段顺序：

1. 主诉
2. 现病史
3. 既往史
4. 个人史
5. 家族史
6. 月经史
7. 生育史
8. 中医四诊及专科查体
9. 辅助检查

生成规则：

- 主诉使用主要症状/体征及持续时间，避免直接抄写整段对话。
- 现病史按时间顺序组织起病、症状演变、诊疗经过和一般情况。
- 未明确描述的普通背景项目可归纳为“未述特殊”或“未见明确异常”；关键问诊、查体、检验、手术和风险不得推定正常。
- 月经史、生育史只在患者适用时生成；不适用时明确写“不适用”。
- 查体结论和辅助检查只整理已提供内容；未提及的检查或体征直接省略。
- 入院记录的专科查体只写西医专科查体，不写中医四诊；输入中的舌象、脉象留作首次病程中医辨证。

## 首次病程记录

字段顺序：

1. 中医辨病辨证依据
2. 中医鉴别诊断
3. 西医诊断依据
4. 西医鉴别诊断
5. 诊疗计划

生成规则：

- 中医辨病辨证依据必须写清主症、医生提供的舌脉、病位、病性和证候判断理由，不得另立与医生证型冲突的辨证。
- 中医鉴别诊断只能讨论中医病证、证候和病机，应说明关键四诊与鉴别要点，不得混入西医鉴别诊断。
- 中医辨病辨证与治则治法必须使用中医病证体系；不能用肺炎、感染等西医病名替代“咳嗽”“肺痈”等中医辨病内容。
- 西医诊断依据应按症状、体征、实验室检查和影像学证据组织。
- 西医鉴别诊断应结合缺失信息和待查项目，避免无依据地排除疾病。
- 鉴别资料不足时，可启用联网检索指南、综述和公开病例；只采用可核验且与当前患者相关的资料，检索失败或无相关结果时明确说明资料不足。
- 诊疗计划分为检查计划、评估计划、治疗计划和观察计划；仅生成原则性计划，不自动开具处方。
- 医生给出的治疗方向是诊疗计划的起点，应扩展为检查、监测、中医治则治法、西医处理原则和复评安排。
- 首次病程必须生成诊疗计划，不得省略或输出占位提示。
- 入院记录和首次病程默认启用联网检索，优先参考指南、综述和中医病证资料；检索内容只补充医学知识，不能虚构本患者事实。
- 每个栏目可追加“言简意赅”“引经据典”“增加鉴别诊断”等要求，但不得覆盖安全约束。

## 普通病程记录

字段：病情变化、生命体征与查体、辅助检查、病情分析、诊疗计划。

只整理本次新增资料，不重复整份入院记录。

## 手术记录

字段：一般项目、术前诊断、术中诊断、手术名称、术者及助手、麻醉方式、手术经过、术中所见、标本处理、术后处理。

手术经过需按操作顺序描述。不得补写未提供的手术步骤、失血量、植入物或标本去向。

## 手术同意书

医生输入：

1. 推荐手术方案（方案一）
2. 备选方案（方案二）
3. 备选方案（方案三）
4. 是否允许联网检索指南和专业资料

生成结构：

1. 疾病介绍，正文限定 200–300 个中文字符。
2. 方案一：使用医生选择的推荐方案名称，列出优点、缺点、适用范围和关键不确定性。
3. 方案二：使用第一个备选方案名称，列出优点、缺点并与推荐方案比较。
4. 方案三：使用第二个备选方案名称，列出优点、缺点并与推荐方案比较。
5. 手术相关风险：根据患者全部资料、合并症、当前用药、检验检查、拟施术式和麻醉方式自动汇总。

生成规则：

- 汇总左侧全部原始输入及此前生成的病历文书，不得只依据最后一条输入。
- 不得把医生未选择或未录入的方案强行写入“推荐方案”。
- 每个方案的优缺点必须包含手术创伤、预期获益、恢复过程、主要风险和再次手术可能性；资料不足时标记“需结合术式核实”。
- 风险至少考虑麻醉、出血与输血、感染、神经血管损伤、血栓栓塞、植入物或固定失败、术后功能恢复及基础疾病加重。
- 可调用联网检索 API 查询指南和专业资料，但必须返回来源、日期和适用条件；不得直接复制无法核验的网络内容。
- 互联网内容只作为风险提示参考，不能替代医生对具体患者的判断，不能自动生成签名或代替知情同意过程。
- 手术同意书正文生成后仍需医师逐项核对并向患者说明。

## 术前小结

来源：全部患者原始资料、此前生成文书、手术同意书。

当前版本只生成以下两个模块：

1. **手术困难和预防并发症的措施及注意事项**
   - 综合患者基线情况、重要脏器功能、局部解剖条件、拟施术式和麻醉方式。
   - 写明预计手术难点、关键风险环节、预防措施、监测要求及异常情况处置原则。
   - 不得虚构术者经验、预计出血量、手术时长或具体器械。
2. **手术者术前查看患者相关情况**
   - 写明手术者已查看患者、核对身份和手术部位/侧别、确认诊断和影像、评估手术指征及术式。
   - 纳入过敏史、当前用药、检验检查、知情同意和患者/家属意见。
   - 未提及的复核内容直接省略，不得写成已经完成不存在的复核，也不输出占位句。

## 术前讨论

来源：患者全部资料、手术同意书和术前小结。

当前版本只生成以下两个模块：

1. **术中及术后可能出现的风险及应对措施**
   - 按术中风险、术后近期风险和术后恢复风险组织。
   - 每项风险需说明可能原因、监测方式和应对措施，避免只列病名。
2. **特殊的术前准备内容**
   - 根据最终术式、合并症和当前用药生成血液准备、抗菌药物、抗凝药物、麻醉评估、植入物/耗材及监护资源等准备项。
   - 不得自动停用药物或给出无依据的剂量；需写明由医师按规范确认。

## 出院小结

字段：入院情况、入院诊断、诊疗经过、出院诊断、出院情况、出院医嘱、复诊建议。

出院诊断必须来自医师确认信息；未明确的诊断标记为“待确认”。

## 疑难病例讨论

字段：讨论时间与地点、参加人员、病例摘要、讨论目的、各发言人意见、讨论结论、后续诊疗计划。

发言意见不得虚构具体人员姓名和观点，缺少相应记录时省略该条意见。

## 其他

当前版本不开放。后续需要单独定义模板和强制字段，不得使用通用自由模板直接生成正式病历。
