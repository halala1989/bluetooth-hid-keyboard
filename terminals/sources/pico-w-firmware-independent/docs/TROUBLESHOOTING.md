# 故障排查（TROUBLESHOOTING）

按"现象 → 原因 → 处理"整理常见问题。先确认固件版本（CI 产物号）与 Android 端版本一致。

## 1. 烧录 / 启动类

| 现象 | 原因 | 处理 |
|---|---|---|
| Pico W 不启动、无反应 | UF2 写入失败 / 供电不足 | 重新按住 BOOTSEL 烧录；换数据线/供电 |
| 看不到 `RPI-RP2` 盘 | BOOTSEL 未按住、线不支持数据 | 重新进 BOOTSEL；换线 |
| 只亮电源灯不广播 | 固件未正常运行 | 用串口看 `main.c` 启动日志（UART0） |
| 反复重启 | 代码异常 / 看门狗 | 检查 USB 描述符是否卡死，临时去掉 HID 初始化验证 |

## 2. BLE / 连接类

| 现象 | 原因 | 处理 |
|---|---|---|
| Android 扫描不到 `PICO-W-KEYBOARD` | 广播未开启 / 距离过远 / 名称不符 | 确认固件已运行；靠近设备；核对广播名 |
| 能扫描但连接失败 | 连接参数不匹配 / 已连接他机 | 断开其他连接；检查 `btstack_config.h` 连接数 |
| 连接后立即断开 | 配对/安全策略（SM）配置 | 检查 `sm_init` 与 IO capability 配置 |
| 写入一直失败 | MTU 未协商 / 单帧超 240 B | Android 端确认 `negotiatedMtu`，`currentMaxPayload ≤ 240` |
| 丢帧 / 文本乱序 | 无线干扰、并发写 | Android 端改为串行队列；靠近设备重试 |

## 3. USB HID / 注入类

| 现象 | 原因 | 处理 |
|---|---|---|
| 主机没反应，设备管理无 HID | 主机未完成 USB 枚举 | 重新插拔；确认 `tud_hid_ready()` |
| 只打出部分字符 | 中文字符被跳过（固件仅 ASCII） | 输入英文/ASCII 测试；或扩展 `usb_hid.c` |
| 打出的是错误字符 | 键盘布局差异（非 US 布局） | Windows 切回 US 布局；或适配本地布局 |
| 按键连发 / 卡住 | 注入节奏过快 | 调大 `send_press_release` 间隔（当前 5ms） |
| 大写/符号不正确 | Shift 修饰符映射错误 | 检查 `usb_hid.c` 的 `ascii_map[]` 修饰位 |

## 4. 构建 / CI 类

| 现象 | 原因 | 处理 |
|---|---|---|
| 本地 `cmake` 报 SDK 未找到 | `PICO_SDK_PATH` 未导出 | `export PICO_SDK_PATH=...` 后重试 |
| CI 编译失败 | 工具链/SDK 版本 | 参考 `BUILD.md` §7 错误对照表 |
| 产物下载后无法烧录 | 下载的是 ELF/HEX 而非 UF2 | 下载 `.uf2` 产物 |

## 5. 性能 / 稳定性

| 现象 | 原因 | 处理 |
|---|---|---|
| 长文本注入慢 | 串行逐帧 + 逐按键注入 | 单条消息 ≤2048 B；减少过短文本 |
| 长时间运行后失效 | BLE 连接老化 / 栈内存泄漏 | 断电重启；检查 NVM 与连接池配置 |
| 注入时 USB 与 BLE 相互干扰 | 分时轮询主循环被长时间阻塞 | 长文本可分多条发送，避免单次注入阻塞过久 |

## 6. 需要提 issue 时

附上以下信息能加速排查：

- 固件 CI run 号 / 本地 commit；
- Android 端版本与机型、Android 版本；
- `btstack_config.h` 关键宏；
- 串口日志（UART0，`ENABLE_LOG_INFO`）；
- 复现步骤与期望/实际行为。
