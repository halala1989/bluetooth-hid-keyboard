# 住院全流程管理（v3.2 Beta）

本分支在原有的手机蓝牙 HID 键盘基础上新增了住院患者工作台。键盘注册、Unicode 输入模式、速度控制和大模型功能仍保留在「键盘工具」页面。

## 已实现

- 患者列表：姓名、年龄、床号、病区、入院诊断、过敏史、患者状态和文书数量。
- 患者详情：新增和编辑基本信息，状态支持“在院 / 待出院 / 已出院”。
- 当前 v4.0-test21 患者详情只保留姓名、性别、年龄；只有点击病例输出区底部“保存到患者详情”的文书才进入患者详情下方。
- 每次生成文书时可追加一段自然语言资料；模型必须先合并左侧全部资料与本次补充内容，再生成文书。
- 左侧完整时间线作为资料池；模型根据文书类型判断相关性，不强制引用全部记录。所有开放文书的生成都必须经过模型。
- 手术同意书从自然语言资料自动提取任意数量的推荐方案和备选方案，不再提供固定三个方案输入框。
- 左侧资料按时间戳排列；旧记录可重新编辑，正文更新但原始时间保持不变，生成时按时间线表达病情变化。
- 入院记录和首次病程中，未提及的常规背景项目按阴性整理；医生给出的舌脉、中医病名和证型优先用于中医诊断依据、鉴别诊断和诊疗计划，默认启用联网参考资料。
- 病例文书：入院记录、首次病程、日常病程、查房、会诊、操作记录和出院小结。
- 文书模板：病程骨架、SOAP、出院小结；模板只提供结构，不自动生成医学结论。
- 每类文书生成前可导入 `.xlsx`/`.csv` 患者资料，逐行转为左侧原始资料。
- 患者主界面“书写规范”入口可导入和管理全局 Markdown Skill；所有病历模块自动应用该规则，与病历安全规范冲突时后者优先。
- 在 Skill 预览下方可输入自然语言修改要求，调用 DeepSeek/MiMo 生成修改后的完整 Markdown；成功后自动保存，失败时不覆盖原规则。
- “当前规则”预览支持独立纵向拖动；AI 修改成功后自动滚动到变化段落并高亮显示。
- 入院记录、首次病程和手术同意书等类型可以重复生成多份；每份文书有独立标签和保存状态。
- 未保存文书持续保留在病例输出区；保存后才写入患者详情，长按文书标签可确认删除。
- 首页统计精简为患者总数、病例总数和出院病例数；病例数按患者已保存文书汇总。
- 患者详情底部支持办理出院；办理后状态更新为“已出院”，患者与文书继续保留，并计入出院病例统计。
- “删除患者及全部本地文书”会清理患者、SQLite 历史文书、加密文书记录和工作台草稿。
- 手术同意书与普通病程使用相同的配置生成流程，不再要求额外点击联网检索或汇总资料生成。
- 手术同意书的显示与输出顺序固定为疾病介绍、方案一至方案 N、手术相关风险；方案按编号排序并去除重复项。
- 手机 HID 输出的全部档位较 Test22 再提速约 10%，第 10 档最低延迟为 3ms；链路丢字时可手动降低速度档位。
- 病例草稿：编辑后自动保存，也可手动保存。
- 电脑输出：复用 App 内共享的蓝牙 HID 会话，把病例正文输入目标电脑当前光标位置。
- 统一终端选择：设置页可手动选择手机蓝牙 HID、Pico W、ESP32-S3 Super Mini、YD-ESP32-S3 N16R8 或旧 ESP32 BLE HID。
- 终端状态灯：设备选择上方实时显示连接成功或等待连接状态。
- 蓝牙电脑配对：选择手机蓝牙终端时弹出电脑配对子菜单，可连接已配对电脑或让电脑重新发现本机。
- 外接板输出：Pico/ESP32/YD-ESP32 使用相同的 BLE 1234/1235/1236 协议，输出路由会把病例文本发送到当前选择的板子。
- 全部终端源码已归档在 `terminals/`，包括多个历史分支和两个独立 Pico 仓库。
- 大模型选项当前只保留 DeepSeek 和小米 MiMo，API Token 在统一设置页配置。
- Token 保存前会先调用当前模型做连通性测试；测试失败时保留已保存的旧 Token，不覆盖为无效值。

## 本地数据

- SQLite 数据库位于 App 私有目录，不提供云端同步。
- 姓名、病案号、联系方式、诊断、过敏史和病例正文使用 Android Keystore 的 AES/GCM 密钥加密后存储。
- `android:allowBackup="false"`，避免系统默认备份患者数据。
- 演示患者带有 `DEMO` 编号和显式演示标记，不能用于真实诊疗。

## 使用流程

1. 打开 App，新增患者并填写基本信息。
2. 进入患者详情，新建病例文书或从最近文书继续编辑。
3. 在「键盘工具」中启动模拟蓝牙键盘，并在目标电脑完成配对。
4. 回到病例编辑页，确认右上角显示“输出已连接”。
5. 点击“发送到电脑”，确认目标窗口后开始 HID 输出。

## 构建

```powershell
$env:JAVA_HOME="C:\Program Files\Java\jdk-17"
$env:ANDROID_HOME="C:\Android\Sdk"
cd android
.\gradlew.bat assembleDebug --no-daemon
```

APK 输出：

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

## 安全边界

当前版本是可运行的本地工作流原型，不是经过医疗器械注册、临床验证或医院信息安全审批的生产系统。正式用于住院患者前，至少需要完成机构授权、账号与角色权限、审计日志、数据保留与删除策略、备份恢复、传输加密和临床安全验证。
